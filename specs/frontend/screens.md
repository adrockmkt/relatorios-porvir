# Telas

## Setup inicial

Criacao do primeiro admin quando o banco ainda nao possui usuarios.

## Login

Tela simples com:

- logo
- titulo
- slogan
- email
- senha
- mensagem de erro

## Dashboard do cliente

Primeira tela para viewer.

Elementos:

- logo do cliente
- nome do cliente
- cards de resumo
- filtros por periodo
- lista de relatorios publicados
- ultimo relatorio em destaque

## Relatorios

Tela administrativa para listar e gerenciar relatorios.

Elementos:

- busca
- filtros
- tabela/lista
- botao novo relatorio
- acoes editar, publicar, arquivar, excluir

## Detalhe do relatorio

Elementos:

- titulo
- cliente
- periodo
- status
- descricao
- links
- acoes administrativas

## Clientes

CRUD de clientes.

Elementos:

- logo
- nome
- slug
- descricao
- status
- usuarios vinculados

## Usuarios

CRUD de usuarios.

Elementos:

- nome
- email
- role
- status
- clientes permitidos
- trocar senha

## Configuracoes

Branding global.

Elementos:

- logo do topo
- titulo
- slogan
- nome publico da instalacao

## Auditoria

Lista filtravel de acoes administrativas e eventos de login.
