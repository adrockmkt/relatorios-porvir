# Integracoes de Links Externos

## Objetivo

Cadastrar links que apontam para relatorios hospedados em outras plataformas.

## Destinos suportados no MVP

- Looker Studio
- Google Drive
- Google Sheets
- PDF externo
- Google Slides
- dashboard externo
- documento
- outro

## Validacoes

- URL obrigatoria
- URL deve iniciar com `https://`
- titulo do link obrigatorio
- tipo de destino obrigatorio

## Boas praticas

- usar nomes claros, como `Dashboard mensal - Looker Studio`
- evitar links encurtados quando o destino precisa ser auditavel
- manter permissoes do destino alinhadas ao publico esperado
